# VLT Studio Portfolio

A portfolio of engineering, design, and creative work.

## Architecture

**Frontend**

- React
- Next.js
- TypeScript

**Backend**

- Node.js
- Express.js

**Database**

- MongoDB

**Styling**

- Tailwind CSS
- GSAP

**Hosting**

- Vercel

## Key Decisions

**Static-first Rendering:** Optimizes for speed, SEO, and simplicity.

**Content-driven Structure:** Decouples content from code for easier iteration.

**Component System:** Reusable, composable, and scalable.

## Performance

- Optimized images (Next/Image)
- Automatic code splitting
- Minimal client-side JavaScript

## Design Principles

- Accessibility-first
- Performance-driven
- Simplicity over abstraction
- Built for extensibility
